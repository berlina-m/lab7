## Summary

SplitSmart must support accounts, groups, shared expenses, approval, notifications, pairwise balances, payments, reports, and the complete web/Android/iOS product scope (FR-001–FR-015, NFR-001–NFR-006). The constitution also defines a Java 21/Maven Java Swing MVP boundary, JUnit 5, PlantUML, Swing/business-logic separation, and BigDecimal monetary arithmetic. This plan documents a proposal only; the specification remains Draft and all unapproved choices remain open.
